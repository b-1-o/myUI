# myUI

Multi-page portfolio UI for **b-1-o** — frontend developer / UI engineer.

## Live

https://b-1-o.github.io/myUI/

## Pages

| Route | Description |
|-------|-------------|
| `/` | Home — CircularCarousel + Enter |
| `/menu` | OptionWheel links |
| `/works` | Masonry works (monochrome) |
| `/about` | About + PatternWaves background |

## Setup

```bash
npm install
npm run dev
```

Deploy: push to `main` (GitHub Actions → Pages).
