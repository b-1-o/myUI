# MyUI

> An interactive multi-page portfolio experience for b-1-o, combining frontend engineering with WebGL, motion, and visual design.

MyUI uses custom rendering, smooth scrolling, layered effects, and responsive optimizations to keep the visual experience polished across devices.

## Highlights

- Multi-page portfolio interface
- WebGL-powered visual effects
- Three.js and OGL rendering
- Smooth scrolling with Lenis
- Post-processing effects
- Responsive layouts
- Mobile-specific rendering optimizations
- Custom navigation and transitions
- Performance-conscious animation architecture

## Tech Stack

React 19 · Vite · React Router · Three.js · React Three Fiber · OGL · Postprocessing · Lenis · gl-matrix · JavaScript · CSS

## Getting Started

```bash
npm install
npm run dev
npm run build
npm run preview
```
